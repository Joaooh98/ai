# exemplo

Copie este arquivo para `<nome>.md` — ou, mais simples, use:

```bash
./workspace/go add /caminho/do/projeto
```

O `name` precisa ser kebab-case minúsculo e bater com o nome do arquivo. O `path`
aceita `~`. Nada abaixo do frontmatter é lido por script: este corpo é seu
caderno sobre o projeto.

O que a **equipe** carrega em toda invocação não é isto — é o
`.claude/toolbelt.md` gravado dentro do próprio projeto pelo `/setup`. Use este
espaço para o que é seu: por onde começar, o que você sempre esquece, qual
ambiente subir.
